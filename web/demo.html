Actually running

  • Layout — taffy, unmodified, same crate the native build uses
  • Text shaping + rasterizing — cosmic-text, own glyph cache
  • Paint — rects, rounded corners, borders, clipping, all hand-built on tiny-skia
  • Every widget on screen — Button, TabBar, Switch, icons — the real, shared widget code
  • Click + hover dispatch, through the same event module the desktop shell uses

Not in this build

  • Downloading anything — yt-dlp is a subprocess; browsers can't spawn one
  • Conversion or playback — same problem, plus no ffmpeg
  • The library database — bundled SQLite doesn't target wasm32 this way
  • Everything on screen below is fabricated demo data, not real

Reasoning, scope, and what was deliberately cut: docs/adr/0005-wasm-render-experiment.md in the rustydlp repo.
