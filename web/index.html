rustyDLP — WebAssembly render experiment

Layout and paint only, running in the browser. Downloads, conversion and playback need a subprocess and a real filesystem, neither of which a browser sandbox has, so this build fabricates its own screen data instead of talking to yt-dlp or a library database. See docs/adr/0005-wasm-render-experiment.md in the repo for the scope and the reasoning. Winit creates the canvas below itself and appends it here on load.
